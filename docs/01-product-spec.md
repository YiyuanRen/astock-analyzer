# 阶段1：产品方案设计

> 状态：✅ 已对齐。本文件为冻结的产品需求，变更需用户确认。

---

## 1. 核心价值

用户看好一支 A 股股票，但不确定精确买卖价。系统基于缠论做多级别分析，提供：
- "现在能不能买"的判断（买卖点类型）
- 精确的介入价区间 / 点位
- 止损价、目标价、赢赔比
- 买点出现时主动推送通知（任务式跟踪）

**重要预期对齐：** 缠论不会吐出单一的"魔法买入价"数字，而是给一套**决策框架 + 价格锚点**。用户据此自行决策、线下操作。

---

## 2. 缠论核心概念（供报告解读参考）

### 中枢位置含义
中枢 = 至少三段连续重叠走势形成的价格平衡区（有上沿、下沿）。价格相对中枢位置：

| 位置 | 含义 | 操作意义 |
|---|---|---|
| 中枢**上方** | 多头突破，上涨主导 | 持股/找回踩买点，别追高 |
| 中枢**内部** | 多空平衡、震荡 | 观望，最难赚钱 |
| 中枢**下方** | 空头击穿，下跌主导 | 空仓等待，别接飞刀 |

### 买卖点类型
- **一买**：下跌末端背驰，抄底点（风险最高、收益最大）
- **二买**：一买后回调不破前低，确认点（较稳）
- **三买**：突破中枢后回踩不跌回，趋势确认点（最适合"看好一支票顺势入场"）
- 一卖/二卖/三卖：方向相反

### 多级别区间套
日线定方向 + 买点类型，低级别（30分/5分）定精确入场时机和价格。把"买入区间"收窄为"买入点位"的关键。

## 3. 分析报告字段（冻结）

```
【基本信息】
股票名称 / 编码 / 当前价格 / 今日涨跌幅 / 分析周期

【缠论信号】
- 当前笔方向：向上 / 向下
- 当前线段方向（趋势）：上升 / 下降 / 震荡
- 中枢位置：价格在中枢 上方/内部/下方（中枢区间 xx-xx）
- 买卖点类型：X类买点 / X类卖点 / 无信号
- MACD背驰：是/否（背驰是买卖点成立的动力学依据）
- 趋势持续：当前笔已运行 N 根K线 / N 天
- 多级别联立结论（日线方向 + 低级别精确入场时机）

【操作建议】
- 操作方向：买入 / 卖出 / 观望
- 建议介入价（区间或精确点位）
- 目标价（前高/中枢上沿/线段目标位）
- 止损价（笔极值/中枢下沿）
- 赢赔比（R:R ratio）
- 仓位建议（一买轻仓/二买加仓/三买重仓）

【辅助信息】
- 支撑/压力位（前期中枢上下沿、前高前低）
- 今日成交量状态：放量/缩量/平量
- 风险提示："仅供参考，不构成投资建议"
```

## 4. 飞书指令集（冻结，共6条）

| 指令 | 用途 |
|---|---|
| `Q 000001` | 即时查询，返回分析报告，不创建任务 |
| `B 000001` | 创建买入跟踪任务，等待买点 |
| `S 000001 [@价格] [数量]` | 创建卖出跟踪任务（含 B→S 切换），价格和数量可选 |
| `C 000001` | 取消该股当前任务 |
| `L` | 列出所有活跃任务 |
| `M [provider] [model]` | 查看/切换 LLM 模型（运行时热切换） |

### S 指令格式细节
```
S 000001              # 最简，不带成本信息
S 000001 @10.45       # 带买入价（可算浮盈/个人止损）
S 000001 @10.45 100   # 带买入价和数量（可算持仓市值/绝对亏损）
```

### 任务逻辑
- **B→S 切换：** 用户线下买入后主动发 S 命令，系统将该股从 B 任务切换为 S 任务。系统不假设买入发生，用户是决策主体。
- **单任务约束：** 同一股票同一时间最多一个活跃任务（B 或 S）。发 S 时若有 B 任务，自动取消 B。
- **买入价/数量：** 可选。不提供也能跑，提供后可展示浮盈、个人止损、持仓市值。

## 5. 分析频率设计（冻结）

| 场景 | 频率 | 触发条件 |
|---|---|---|
| B/S 任务主体分析 | 每交易日 15:05 收盘后一次 | 定时（日线信号只能收盘后确认）|
| B 任务盘中跟踪 | 交易日 9:30-15:00，每 30 分钟 | 定时拉取 3 周期 K 线 → 多级别缠论分析 → 有买点则推送，无信号则静默 |
| S 任务止损监控 | 盘中每 3 分钟检查价格 | 持续运行，触及止损价立即推送 |
| Q 即时查询 | 用户触发即时 | 一次性，可读缓存 |

**B 与 S 盘中逻辑不对称：**
- B 的盘中 = 每 30 分钟完整跑一次多级别缠论分析，有买点信号才推送
- S 的盘中 = 每 3 分钟只拉实时报价比较止损价，不跑完整缠论计算

## 6. 典型工作流

```
用户: B 000001
系统: 立即返回分析报告（如无信号则观望）→ 每日15:05自动分析

[数日后买点出现]
系统主动推送: 000001 出现日线三类买点
             当前价10.48 / 精确入场关注10.3-10.5 / 止损9.95 / 目标11.8 / 仓位30-50%

[用户线下买入后]
用户: S 000001 @10.45 100
系统: 已切换为持仓跟踪，成本10.45，持仓100股，止损9.95，目标11.8，浮盈+0.3%

[持仓期间]
系统推送（止损预警）: 000001 当前10.01，距止损9.95仅1.4%，请注意
或（卖点信号）: 000001 出现日线二类卖出信号，建议11.6-11.8区间减仓
```

## 7. 风险提示（必须纳入每份报告）

- 缠论笔/线段划分有一定主观性，不同实现结果可能略有差异
- 日线买点只能收盘后确认，A股次日可能跳空低开，信号有延迟性
- 所有分析仅供参考，不构成投资建议
